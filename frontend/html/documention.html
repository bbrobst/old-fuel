Project Overview

Old Fuel is a web-based platform designed for managing, submitting, updating, and deleting research datasets. It provides an interface for users to interact with the database.

Setup Instructions

1. Clone the Repository

git clone https://github.com/bbrobst/old-fuel.git

cd old-fuel

2. Install Dependencies

# Install Node.js dependencies

npm install

# This installs: express, pg, dotenv, and other dependencies

3. Set Up Environment Variables

# Create a .env file in the backend folder

DB_HOST=localhost

DB_NAME=CarData

DB_USER=postgres

DB_PASSWORD=yourpassword

DB_PORT=5432

PORT=3000

4. Set Up the PostgreSQL Database

Restore from backup file (CarData.backup)

5. Start the Application

# Make sure you're in the backend folder

node server.js

# Or use npm start

npm start

6. Access the Website

Open your browser and navigate to:

http://localhost:3000

# For specific pages:

http://localhost:3000/frontend/html/data-input.html

http://localhost:3000/frontend/html/data-update.html

http://localhost:3000/frontend/html/data-deletion.html
